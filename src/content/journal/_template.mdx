Write the post here in plain Markdown. A blank line starts a new paragraph.

Use `##` for a section break. On this site those render as a short centered
rule rather than a bold heading, so a long post still reads as one document.

> A line starting with a greater-than sign becomes a pull quote, set in the
> display face and indented to the rule.

Write in first person. Short declarative sentences. Specific numbers.
